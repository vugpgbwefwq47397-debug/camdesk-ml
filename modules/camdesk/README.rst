CamDesk
=======

Finite interval shooting with the native Magic Lantern engine.

:Author: CamDesk project (Codex assisted)
:License: GPL-2.0-or-later
:Summary: Configure, arm and stop a finite interval sequence.

Open Prefs > CamDesk. Set interval, delay and cycle count. Arm plan,
exit the menu, hold half-shutter and release. Stop / Disarm disables
the native intervalometer. A current exposure may finish normally.

Arming changes native interval settings; it rejects an enabled engine.
The native engine controls shooting. HDR bracketing is rejected.
Use single-shot drive and manual focus for initial camera testing.
Plan edits apply to the next arm; completion disarms the engine.
This build is experimental and has not been validated on a camera.
