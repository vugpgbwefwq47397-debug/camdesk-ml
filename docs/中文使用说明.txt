# 安装与恢复（中文）

本次成品：CamDesk **0.4.2-hui**，仅对应 **EOS 50D／佳能固件1.0.9／50D.109**。项目可向其他魔灯机型移植，但本包不适用于其他机型。

1. 确认相机菜单的固件版本为1.0.9，且这张CF卡已能正常启动魔灯。全新卡或首次安装用户需先按魔灯上游的50D说明完成基础安装；本包不是首次安装器。
2. 将卡接入读卡器，备份卡内全部文件，尤其是 `autoexec.bin`、`ML` 和照片。核对发布附件的SHA-256。
3. 将card压缩包中的 `autoexec.bin`、`ML` 和说明文件解压到CF卡根目录，合并同名目录并覆盖随包文件。不要将外层文件夹放到卡根目录。不要混用其他构建的核心、符号表和模块。
4. 保留卡上已有 `ML/SETTINGS`、模块启用文件和照片。本包不附带个人设置，也不需要格式化或运行固件升级。
5. 安全弹出，关机插卡后开机。按垃圾桶键显示参数首屏；转动拨轮进入完整菜单。若仍是经典界面，在设置中将界面风格改为“北欧”。
6. 实时取景用INFO切换到魔灯辅助显示状态。若需间隔拍摄工具，在Modules中启用 `camdesk.mo` 并按菜单提示重启，再进入设置中的相机工作台。原生参数首屏不依赖该模块启用。

若显示异常，先关机后把卡接回电脑，恢复事先备份的整套 `autoexec.bin` 与 `ML`；保留自己的照片。不要仅恢复核心而继续使用另一版本的符号表。开卡盖后等待写卡指示灯确认或至少5秒再取卡。

最新版本尚待实机回归。请在提出问题时注明机型、佳能固件、CamDesk版本、镜头、拍摄模式、复现步骤及屏幕照片。其他机型请先讨论移植，勿试用50D二进制包。
